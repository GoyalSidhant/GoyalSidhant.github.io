# Sidhant Goyal Portfolio

Modern Astro-based portfolio with an MDX blog and built-in SEO foundations.

## Tech Stack

- Astro
- MDX (`src/content/blog/*.mdx`)
- TypeScript

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content Editing

- Main site content is in `src/data/site.ts`
- Blog posts are MDX files in `src/content/blog`

## SEO Included

- Canonical URLs and metadata
- Open Graph and Twitter cards
- JSON-LD person schema on homepage
- `robots.txt`
- Auto sitemap via `@astrojs/sitemap`
